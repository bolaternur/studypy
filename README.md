# StudyPy

Интерактивная платформа для изучения Python: 73 урока, 365 задач с автоматической
проверкой и настоящий интерпретатор Python, работающий прямо в браузере через
Pyodide (WebAssembly). Ничего устанавливать не нужно.

Стек: React 19 + Vite + TypeScript, Tailwind CSS v4, Firebase (Auth + Firestore),
Express + Socket.IO, Monaco Editor, Pyodide, Google Gemini для ИИ-наставника.

---

## Требования

- Node.js 20 или новее
- Проект Firebase (конфигурация клиента — в `firebase-applet-config.json`)
- Ключ Google Gemini — только для ИИ-наставника и генерации ежедневных задач
- Service account Firebase — для серверных начислений опыта, монет и предметов

Без Gemini и service account приложение запускается и работает: уроки, задачи,
песочница и редактор не зависят от них. Отключаются только ИИ-функции и
серверные награды.

## Запуск

```bash
npm install
cp .env.example .env
npm run dev
```

Сервер поднимается на `http://127.0.0.1:3000`. Переменные `HOST`, `PORT` и
`CORS_ORIGINS` задаются в `.env`.

## Проверки

```bash
npm run lint
```

`lint` выполняет две проверки: `typecheck` (TypeScript в строгом режиме) и
`validate` (целостность учебной программы — уникальность ID уроков, наличие
тестов у каждой задачи, соответствие чисел на лендинге реальному датасету).

```bash
npm run build
```

## Архитектура

| Часть | Где | Зачем |
|---|---|---|
| Клиент | `src/` | Страницы, компоненты, контекст авторизации |
| Учебный контент | `src/constants/lessons.ts` | 73 урока, 365 задач с тест-кейсами |
| Сервер | `server.ts` | REST API, Socket.IO, прокси к Gemini, доверенные транзакции |
| Serverless | `api/` | Обёртка того же Express-приложения для Vercel |
| Правила доступа | `firestore.rules` | Клиент может менять только `username`, `avatar`, `bio` |
| Проверки | `scripts/` | Валидатор учебной программы |

### Что считается доверенным

Браузеру не разрешено начислять себе опыт, монеты, предметы или записывать
результаты соревнований. Всё это проходит через `server.ts`, где выполняется
проверка Firebase ID-токена, rate limiting и атомарные транзакции Firestore.
Правила Firestore разрешают клиенту менять только косметические поля профиля;
экономика, гильдии, обмены, заявки в друзья и боссы доступны на запись только
сервису с правами администратора.

Ключ Gemini читает только сервер. Браузер обращается к `/api/mentor/*` и
никогда не получает секрет.

## Безопасность и конфигурация

Никогда не коммитьте `.env` и `FIREBASE_SERVICE_ACCOUNT_JSON`. Значения в
`firebase-applet-config.json` — это публичная клиентская конфигурация Firebase,
она не является секретом, но доступ должен ограничиваться правилами Firestore и
настройками API-ключа в консоли Google Cloud.

## Известные ограничения

- Состояние дуэлей и совместных сессий хранится в памяти процесса (`server.ts`).
  Перезапуск или горизонтальное масштабирование их теряет — нужен общий adapter
  для Socket.IO.
- Автоматических тестов нет. `npm run lint` покрывает типы и целостность
  контента, но не поведение.
- Pyodide загружается с CDN jsDelivr и выполняется в основном потоке. Тяжёлый
  или бесконечный пользовательский код может подвесить вкладку.
- Аудит от 10 сентября 2026 года сохранён в `docs/audit-2026-09-10.md`. Часть
  описанных там проблем уже исправлена — документ оставлен как база для
  регрессий.

# StudyPy

StudyPy — пошаговый курс Python в браузере: объяснения, разобранные примеры, самостоятельные задачи, контрольные и проекты. Рядом остаются песочница, тренажёр набора и учебные игры. Счётчики программы вычисляются из материалов.

Стек сохранён: React 19, Vite, TypeScript, Firebase Auth/Firestore, Express, Socket.IO, Monaco и Pyodide.

## Локальный запуск

Требуется Node.js 20+.

```sh
npm ci
cp .env.example .env
npm run dev
```

Откройте http://127.0.0.1:3000. Без service account и Gemini доступны уроки, игры и локальная песочница. Не подключайте рабочую базу для тестовых записей. Публичная конфигурация Firebase находится в firebase-applet-config.json; секретные ключи задаются только серверу через .env.

## Как исполняется Python

src/runtime/python.worker.ts загружает Pyodide 0.26.4 по запросу, включая дополнительные пакеты для импортов (например, sqlite3). Каждый запуск получает отдельный Worker. Остановка и лимит времени вызывают terminate; следующий запуск создаёт новую среду. Загрузка ограничена 45 секундами, обычное выполнение — 5 секундами. Вывод ограничен 20 000 символами; трассировка — 250 событиями и общим бюджетом снимков.

Для input() значения вводятся **до** запуска. Программа не перезапускается для получения очередной строки. Черновики сохраняются на устройстве по стабильным ID задания; при отказе localStorage редактор предупреждает об этом. Если Monaco/CDN недоступен, можно пользоваться простым редактором.

Проверка отделяет stdin, подготовку окружения setup, код ученика, выражение вызова expression, stdout программы и stdout вызова expectedCallOutput. Проверки в браузере видимы и не являются защитой от намеренного изменения результата.

## Контент и сохранение прогресса

- `/pathways` — дерево базового курса и дополнительных последовательностей; `/learn/:moduleId/:lessonId?step=...` или `?task=...` — стабильная ссылка на конкретный шаг.
- `src/course/modules/` — материалы по модулям, загружаемые по необходимости. Полный учебник не входит в начальную загрузку главной страницы.
- `src/course/types.ts` описывает цели, prerequisites, шаги, примеры, виды упражнений, вход/выход, ограничения, постепенные подсказки, тесты и разборы. `index.generated.ts` содержит только лёгкие метаданные, `summary.generated.ts` — счётчики для главной. После редактирования запускайте `npm run course:index`; сборка делает это автоматически.
- База: 12 модулей, 125 уроков, 478 упражнений; 356 требуют самостоятельного кода. Две отдельные итоговые работы. Проектные уроки включают небольшие работы и этапы комплексной практики. ООП, итераторы/генераторы, декораторы, asyncio, SQL и инструменты имеют отдельные вводные последовательности, не обещающие профессионального освоения одной карточкой.
- `studypy_course_v1_guest` и отдельный ключ пользователя хранят локальные отметки чтения, решения, факт открытого разбора, закладки, точное место и до 300 попыток. Новый курс **не синхронизирует** результаты с сервером и не начисляет XP. Открытое решение помечает последующие попытки как выполненные с помощью. Завершение модуля требует всех обязательных упражнений, контрольной и проекта; самостоятельность контрольной показана отдельно. Повторение через 1, 3, 7 дней — рекомендация без уведомлений и штрафов.
- Прежние `src/constants/lesson-catalog.ts`, `src/constants/lessons.ts`, `src/content/lessons/` сохраняют 63 вводных урока и 83 задачи. Старые URL, 10 алиасов `*-practice`, черновики и отметки доступны из дополнительного списка. Сопоставление со свежей программой — `src/course/legacy-links.ts`; старая отметка не даёт зачёт новых упражнений.
- Только прежняя отметка `/api/lessons/complete` может синхронизироваться в авторизованном сценарии. Это отдельный прежний формат; ошибки сервиса не удаляют локальный код.

Синхронизированный учебный прогресс помечен self_reported, не начисляет XP/монеты и не служит рейтингом. Старые XP и предметы сохраняются как игровые данные, отдельно от знания Python.

## Что пока ограничено

Пока нет изолированного доверенного серверного исполнителя Python, /api/arcade/complete, /api/daily-challenges/complete, /api/bosses/complete, /api/bosses/global/contribute и /api/tournaments/complete отклоняют клиентские результаты. Старые socket-события дуэлей также возвращают unavailable. Практика, игры и серии задач остаются доступны.

Покупки, использование существующих предметов, сделки и социальные действия сохраняют проверку токена, rate limiting и транзакции. Неосуществлённые эффекты предметов не обещаются; платное случайное обновление магазина отключено. Firestore rules ограничивают создание начального профиля и последующие клиентские изменения. Изменённые rules нужно отдельно проверить в эмуляторе перед развёртыванием: эта работа не публикует их в Firebase.

Галерея и совместные сессии используют существующие сервисы. Совместные сессии хранятся в памяти процесса; перезапуск их завершает. Локальные инструкции Git, IDE, Docker, настоящие потоки и процессы не изображаются как запущенные внутри браузера.

## Наставник, тренажёр и обратная связь

Наставник использует 120 отредактированных справок по всем 63 темам программы, включая 28 типов ошибок и 24 подробных разбора. У каждой справки есть первичные источники, диагностика и следующий шаг. Краткая подсказка отделена от полного примера. 118 примеров проверяются общим раннером. Справочный поиск не называется ИИ; при недоступности сервиса браузер лениво загружает ту же базу, не увеличивая начальный JS-бандл всем корпусом.

`/typing` — «Набор кода Python»: 80 различных исполняемых программ, 10 тем и три уровня сложности. Последовательность идёт от `print()` к функциям, обработке ошибок и небольшим программам. В каталоге можно выбрать тему и уровень. Для завершения нужно точно набрать весь код, включая отступы; неправильный последний символ и ручная остановка не засчитываются. Черновик, завершённые уровни, лучшее время и точность сохраняются на устройстве. Исправленные ошибки остаются в статистике. Это тренировка синтаксиса и набора, а не проверка самостоятельного решения или оценка знания Python; XP нет. Старые URL печати в Arcade перенаправляют сюда, старые сохранённые настройки не удаляются.

Необязательный учебный разбор связывает каждый из 80 уровней с конкретной подтемой нового курса: объяснение → прогноз → набор → перенос приёма → самостоятельная задача с настоящим Python. Большие объяснения берутся из общих материалов, не копируются вручную. Карта ссылок и типичных ошибок — `src/course/typing-links.ts`. Обычный набор доступен сразу; прогноз и WPM не добавляют зачёт курса.

Меню плавно открывается и закрывается; пункты получают небольшой отклик при наведении и нажатии. Reduced motion убирает перемещения. Мягкие звуки синтезируются локально через Web Audio, выключены по умолчанию и включаются значком динамика или в меню; настройка сохраняется. В меню доступны громкость 0–100% и кнопка «Проверить звук». Используется короткий приглушённый звук на основе сглаженного шума и затухающего тона; проба не теряется из-за ограничителя повторных нажатий. MP3 с внешних сайтов не загружаются.

Начальный индикатор встроен в HTML до React, а через 12 секунд предлагает повторную загрузку. Он не удерживает пользователя искусственно и не показывает выдуманный процент. Основа — ldrs Ring (MIT), см. `docs/loader-attribution.md`. Inter и JetBrains Mono размещены локально с OFL-лицензиями, чтобы Google Fonts CSS не блокировал первый показ; см. `docs/fonts-attribution.md`.

## Проверки

Установите Python 3 для редакторских тестов; задайте PYTHON_BIN, если команда Python не находится автоматически. Все исполняемые исходники этих тестов принадлежат репозиторию. Сервер никогда не запускает присланный учеником Python в своём процессе.

```sh
npm run lint
npm test
npm run build
node scripts/build-api.mjs
```

lint проверяет TypeScript, старый контент и структуру нового курса: ID, prerequisites и циклы зависимостей, тесты, ссылки, счётчики, все связи тренажёра. npm test сохраняет старые регрессии и добавляет `test:course-progress`, `test:course` и `test:course-examples`: исполняются примеры, эталоны на всех входах, альтернативы и публичные примеры условий; заготовки, постороннее присваивание и характерные неверные решения должны отклоняться. Редакторская проверка запускает только исходники из репозитория в отдельном временном каталоге; она не является серверным исполнителем ученического кода. Успех lint/build сам по себе не доказывает правильность обучения.

scripts/browser-*.js — дополнительные Playwright-сценарии реального Pyodide, уроков, игр, CDN/сети и диалогов. Для них запустите dev на порту 3000 и preview на 4173. Скриншоты пишутся в test-results/. Сценарии не отправляют публикации и тестовые записи в рабочую базу.

Подробная редакторская проверка: docs/content-review-2026-10-16.md. Исходный аудит сохранён в docs/audit-2026-09-10.md как исторический документ.

Расширение курса: `docs/course-before-2026-10-17.md`, `docs/course-expansion-2026-10-17.md`, `docs/course-independent-review-2026-10-17.md`. Сквозной путь новичка и четыре ширины проверяют `scripts/browser-course-flow-smoke.js` и `scripts/browser-course-layout-smoke.js`; весь новый Python-каталог в реальном Worker — `scripts/browser-course-content-smoke.js`.

# Индикатор загрузки StudyPy

Использована небольшая адаптация Ring из [GriffinJohnston/ldrs](https://github.com/GriffinJohnston/ldrs), лицензия MIT, автор Griffin Johnston.

Проверенный revision: `f759f65beb8ab4f4a1f010438072180693ca01ec` (проверено 16 октября 2026 года).

Первичные исходники:

- [SVG/React Ring.tsx](https://github.com/GriffinJohnston/ldrs/blob/f759f65beb8ab4f4a1f010438072180693ca01ec/src/react/Ring.tsx)
- [Анимация Ring.scss](https://github.com/GriffinJohnston/ldrs/blob/f759f65beb8ab4f4a1f010438072180693ca01ec/src/react/Ring.scss)
- [Лицензия MIT](https://github.com/GriffinJohnston/ldrs/blob/f759f65beb8ab4f4a1f010438072180693ca01ec/LICENSE)

Полный текст лицензии сохранён в `public/third-party-licenses/ldrs-MIT.txt` и входит в сборку. Copyright (c) 2022 Griffin Johnston.

Адаптация не устанавливает ldrs и не загружает библиотеку с CDN. Сохранены вращение SVG и изменение длины дуги; классы, размер, цвета и оболочка приведены к StudyPy. Добавлены reduced motion, доступное текстовое состояние и действие при долгой загрузке.

Начальный индикатор находится прямо в `index.html` внутри `#root`. Его стили встроены в head: текст и SVG появляются до получения JavaScript приложения. Первый React render заменяет содержимое root немедленно; искусственного минимального времени показа нет. `LoadingScreen.tsx` переиспользует этот вид для ожидания lazy-маршрутов.

Через 12 секунд CSS открывает сообщение о долгой загрузке и действие «Обновить страницу». У bootstrap это обычная ссылка на текущий документ, которая работает даже при недоступном JS приложения; у React-компонента — `location.reload()`. Индикатор не показывает выдуманные проценты и не утверждает, что загрузка завершилась. При выключенном JavaScript bootstrap скрывается, остаётся существующее сообщение noscript.

Это обратная связь о фактическом ожидании, а не ускорение сети или исполнения приложения. Для измерения холодного запуска нужны отдельные замеры с очищенным HTTP-кешем и фиксированным профилем сети/CPU.

## Повторение проверки отказа

`node scripts/fixtures/loader-server.mjs` открывает изолированную копию HTML на 127.0.0.1:3002. Запрос app JS намеренно возвращает 503; все другие файлы недоступны. Проверь начальный индикатор, сообщение через 12 секунд и обновление документа. Это отдельная тестовая страница; обычный StudyPy запускается на 3000.
